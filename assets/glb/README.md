# Canonical GLB exports

Store web-ready `.glb` exports here.

Recommended structure:

```text
assets/glb/<asset-id>/<asset-id>.glb
```

These exports are canonical runtime assets in the repository. During rapid inspection, `apps/lab` can also open any GLB directly from disk with the file picker. Stable Vite-served copies may be placed under `apps/lab/public/models/`.
