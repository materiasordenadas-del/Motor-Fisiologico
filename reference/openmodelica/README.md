# Referencias OpenModelica / Physiolibrary

Cada modelo matemático migrado al Engine TypeScript debe tener una carpeta versionada con:

- `provenance.yaml`
- `inputs.csv`
- `outputs.csv`
- `tolerances.yaml`

El dataset de referencia no se reemplaza silenciosamente. Un cambio de modelo, versión, solver, parámetros o condiciones iniciales crea una nueva referencia o una actualización documentada.
